# KoreaMate V3 第七阶段：免费图片翻译设计

## 目标

在现有统一翻译入口中增加韩文图片识别和翻译能力，不新增标签页，不要求用户判断图片类型，也不引入按次收费的视觉模型。

首个交付切片覆盖普通韩文图片与韩国餐厅菜单。语音识别和韩语朗读留在后续切片。

## 用户体验

- 翻译页现有输入区增加附件按钮，移动设备可拍照或从相册选择图片。
- 支持 JPG、PNG、WebP，单次最多 4 张。
- 浏览器在发送前将图片最长边压缩至 1600px。
- 系统自动区分普通图片和菜单，用户不需要选择模式。
- 普通图片显示韩文原文、中文译文和无法确认的片段。
- 菜单图片显示菜名、中文含义、价格、主要食材及可确认的饮食提示。
- OCR 无结果或图片质量不足时，明确提示重新拍摄，不编造内容。
- PaddleOCR 服务不可用时，图片任务可信失败，但文字翻译继续可用。

## 系统架构

数据流如下：

```text
浏览器压缩图片
  → NestJS 接收图片翻译消息
  → PaddleOCR MCP 使用韩文模型提取文字
  → DeepSeek 判断内容类型并生成结构化中文结果
  → 通过现有 SSE 返回进度与结果
  → PostgreSQL 仅保存结构化文本
```

PaddleOCR MCP 使用 ModelScope 收录的官方开源实现。开发环境在本机运行独立 Python 进程；生产环境作为独立容器运行。主 API 通过 MCP 协议访问，不将 Python 推理依赖嵌入 Next.js 或 NestJS 进程。

模型选择为 PP-OCRv5 韩文识别模型。OCR 只负责提取可见文字，菜单理解与中译由项目现有 DeepSeek Provider 完成。

## API 与契约

扩展翻译消息内容，增加图片数组。图片请求继续使用现有会话、任务、幂等键和 SSE 事件体系。

新增结果字段：

- `kind`: `text`、`menu` 或 `unknown`
- `sourceText`: OCR 提取的韩文原文
- `summary`: 中文概述
- `sections`: 普通图片的段落翻译
- `menuItems`: 菜名、中文名、价格、食材与提示
- `uncertainText`: 无法可靠确认的文字
- `provider`: OCR 与翻译 Provider 信息

新增任务事件：

- `translation.image.started`
- `translation.image.ocr.ready`
- `translation.image.ready`

## 数据与隐私

- 原图只在当前请求和任务执行期间存在于内存，不写入数据库或长期文件目录。
- 历史记录保存用户的图片消息占位、OCR 原文和结构化翻译，不保存图片本身。
- 日志不得输出 Base64、完整图片内容或敏感识别文本。
- 图片任务结束后释放图片引用。
- 首版不增加对象存储、附件表或原图下载能力。

## 限制与防护

- 仅接受 JPG、PNG、WebP。
- 单次最多 4 张，前端最长边 1600px。
- 后端继续执行 MIME、数量、单图和请求总大小校验，不能依赖前端校验。
- MCP 请求设置明确超时；超时、进程离线和无结果返回可理解的中文错误。
- OCR 低置信度内容进入 `uncertainText`，不得自动补全为确定事实。

## 运行与部署

- `PADDLEOCR_MCP_URL` 配置 MCP 地址。
- `PADDLEOCR_LANGUAGE=korean` 固定首版识别语言。
- 本地开发脚本可以同时启动 Web、API 和 OCR MCP。
- Provider 健康检查区分未配置、可用、超时和不可用。
- 生产部署使用独立 OCR 容器，避免模型内存影响主 API。

PaddleOCR 模型本身不产生按次调用费用；本地运行免费，公开部署只承担所在服务器的计算资源成本。

## 测试与验收

测试覆盖：

- 韩文餐厅菜单能生成结构化中文菜单。
- 普通韩文标牌能返回分段译文。
- 混合韩文、中文、英文和数字时保留原意。
- 模糊图片、空识别结果和低置信度结果不产生臆造译文。
- 不支持的格式、超限图片和超过 4 张图片被拒绝。
- PaddleOCR 离线或超时时，文字翻译主路径不受影响。
- 历史恢复后能看到 OCR 文本与翻译结果，但无法取回原图。
- 日志与数据库中不存在 Base64 图片数据。

验收标准：用户从翻译页拍摄或上传一张韩国菜单照片，可以在同一对话中得到可读的中文菜单；整个流程不依赖新的付费视觉 API。

## 暂不包含

- 保存或分享原图。
- 手写体专项识别。
- 自动下单或餐厅支付。
- 语音识别与韩语朗读；它们作为第七阶段后续独立切片实施。
