# KoreaMate V3 第七阶段：语音输入与韩语朗读设计

## 目标

在现有翻译页内补齐免费的语音输入和韩语朗读能力，不增加页面、Tab、服务器语音服务或付费 API。用户仍通过同一个输入框完成文字、图片和语音翻译。

## 范围

本切片包含：

- 使用浏览器 Web Speech API 将中文或韩语语音转为文字。
- 将识别结果写入现有输入框，由用户检查、修改并主动发送。
- 使用浏览器 Speech Synthesis API 朗读韩语翻译结果。
- 处理浏览器不支持、麦克风权限拒绝、无识别结果和朗读中断。
- 增加相应的前端测试和可访问性状态。

本切片不包含：

- Whisper 或其他服务端语音识别。
- 音频上传、录音存储或音频历史。
- 自动发送识别结果。
- 独立语音页面、语音模式或额外导航入口。

## 用户交互

### 语音输入

翻译页输入框右侧保留发送按钮，输入区域内增加麦克风按钮。按钮的可点击区域不小于 44 × 44 像素。

1. 用户点击麦克风按钮。
2. 浏览器请求麦克风权限并开始识别。
3. 页面以简短文字和按钮状态表示“正在听”。
4. 用户再次点击按钮或浏览器返回最终结果后停止识别。
5. 识别文字追加到输入框；已有文字不会被覆盖。
6. 用户可修改文字，再点击发送或按 Enter。

系统不会因识别结束自动发送，避免错误识别直接触发翻译。

### 韩语朗读

当文字翻译结果的目标语言为韩语时，在结果卡片内显示“朗读”按钮。

- 点击“朗读”后使用 `speechSynthesis` 播放 `naturalExpression`，优先选择 `ko-KR` 语音。
- 播放中按钮显示“停止朗读”；再次点击立即停止。
- 新一次朗读开始前取消上一段朗读。
- 页面卸载时取消朗读，避免离开页面后继续播放。
- 中文结果不显示韩语朗读按钮。

## 浏览器适配与降级

语音输入通过 `SpeechRecognition` 或 `webkitSpeechRecognition` 适配。默认识别语言根据输入内容推断：已有韩文时使用 `ko-KR`，否则使用 `zh-CN`。识别结果仍可包含另一种语言，最终语言判断由现有翻译服务完成。

浏览器不支持语音识别时，麦克风按钮保持可见但禁用，并提供“当前浏览器暂不支持语音输入”的可访问性说明。这样可以避免界面位置突然变化，也让用户知道功能存在。

权限拒绝、设备不可用和网络识别失败分别映射为简短中文提示。任何失败都不会清空输入框，也不会影响文字和图片翻译。

如果浏览器不支持 Speech Synthesis，则不显示朗读按钮；文字翻译结果仍正常显示。

## 前端结构

新增两个小型、独立单元：

- `useSpeechRecognition`：负责能力检测、开始、停止、结果、错误与卸载清理。
- `SpeechButton`/结果卡片朗读控制：负责状态展示和 Speech Synthesis 生命周期。

`ConversationScreen` 只负责把识别结果合并进现有输入状态，不包含浏览器 API 的实现细节。现有发送请求、SSE 事件、后端契约和数据库均不修改。

## 隐私与安全

- KoreaMate 前后端不接收、不记录、不保存原始录音。
- 浏览器或浏览器所使用的语音识别服务可能处理音频；首次使用前在界面旁以简短文字说明“语音识别由浏览器提供”。
- 不在日志中输出识别中的临时文本。
- 页面只保存用户最终发送的文字，遵循现有翻译消息数据规则。

## 可访问性

- 麦克风按钮使用随状态变化的 `aria-label`：开始语音输入、停止语音输入、当前浏览器不支持语音输入。
- 识别状态通过 `aria-live="polite"` 宣告，但不反复播报中间结果。
- 朗读按钮具备明确文字或可访问性名称，不以颜色作为唯一状态提示。
- 键盘用户可以操作麦克风和朗读按钮。

## 错误处理

- `not-allowed` / `service-not-allowed`：提示允许浏览器使用麦克风。
- `no-speech`：提示没有听清，可重试或直接输入文字。
- `audio-capture`：提示未找到可用麦克风。
- `network` 和其他错误：提示语音识别暂时不可用，文字输入仍可使用。
- 组件卸载或用户切换页面：停止识别并取消朗读，不显示错误。

## 测试与验收

单元与组件测试覆盖：

- 支持与不支持 Web Speech API 的两种环境。
- 点击开始、再次点击停止、最终结果追加进输入框。
- 已有输入不会被覆盖。
- 识别失败时输入内容保持不变并显示准确提示。
- 识别结果不会自动发送，Enter 和发送按钮行为保持不变。
- 仅韩语结果显示朗读按钮。
- `ko-KR` 语音优先、再次点击停止、页面卸载取消。

验收标准：在支持的 Chrome 或 Edge 中，用户能在翻译页用一次点击开始说话，识别文字经确认后发送，并能用一次点击听到韩语翻译；整个流程不上传或保存录音，文字和图片翻译回归测试继续通过。
